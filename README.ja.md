# Book Props

蔵書を Obsidian で一冊一ノートとして管理し、書店の商品ページで「持っている」「欲しい」を確かめる。Obsidian プラグインと、Chrome などの Chromium 系ブラウザ向けの拡張で構成する。

## できること

- 本ごとに Vault 内に一つの Markdown ノートを作る。初版と改訂版は別の版として扱い、紙と電子は内容が同じと確認できれば同じ版にまとめる。「欲しい」は本単位で、版の所持とは別に記録する。
- Obsidian のコマンドから、本の登録と編集、本棚の検索と絞り込み、版の移動、記録のアーカイブと復元、JSON の入出力を行う。
- 書誌は、ISBN か書名で国立国会図書館サーチから探すか、対応サイトの商品 URL から取り込める。
- 対応サイト（Amazon.co.jp、楽天ブックス、バリューブックス、BOOKOFF オンライン）の商品ページで、拡張が「この版を所持」「別版を所持」「欲しいに登録済み」などを表示する。拡張のポップアップから購入や購入希望を記録し、Obsidian でノートを開ける。

## 動作環境

- Windows または Linux のデスクトップ版 Obsidian 1.13.0 以降。
- 拡張を使う場合は、同じ端末の Chrome などの Chromium 系ブラウザ。Vivaldi でも動作を確かめている。
- スマートフォンでは同期済みの Markdown を読めるが、プラグインと拡張は動かない。

## 導入

[GitHub の最新 Release](https://github.com/YukiIto1999/book-props/releases/latest) の Assets から `book-props-<版>.zip` を取得する。ZIP には Obsidian プラグインとブラウザ拡張が入っている。[導入手順](docs/installation.md)に従って、両方を読み込んで接続する。証明書の登録、追加の実行ファイル、GitHub CLI は不要。

Release には、Obsidian 用の `main.js` と `manifest.json`、Chrome Web Store 用の `book-props-chrome-<版>.zip` も添付する。中身は ZIP と同じファイルである。

## 使い方

1. Obsidian の「設定」→「Book Props」で、Vault の書籍フォルダを指定する。
2. 「Chromeとの接続」で「接続を始める」を押す。ホームの `Book Props` の下に、Vault 名の接続用フォルダができる。
3. 拡張を入れると、拡張の接続設定が開き、読み取るデータと送り先の説明が出る。説明を読んで「同意して使い始める」を押す。同意するまで、拡張は商品ページを読み取らず、Obsidian にも接続しない。同じ画面の「同意を取り消す」でいつでも取り消せる。
4. 拡張の接続設定で「接続用フォルダを選ぶ」を押し、そのフォルダを選んで、ブラウザに編集を許可する。
5. 対応サイトで本の商品ページを開くと、拡張が所持の状態を表示する。ポップアップから購入や購入希望を Vault に記録できる。
6. 接続設定を閉じた後やブラウザを開き直した後に「接続用フォルダの許可が切れています」と表示されたら、接続設定の「今後も自動で接続する」から許可し直す。毎回許可する選択肢を選ぶと、以後は確認なしで接続する。

Obsidian では「書籍を登録・編集」「本棚を開く」「本・版を管理」のコマンドを使う。新しい本ページの名前は、書名に本 ID から作る 8 文字の符号を付けたもの（例：`リーダブルコード (7b91b5a8).md`）になる。同じフォルダの中では、同じ書名の本も別の名前になる。同期の前に 2 台の端末で同じ書名の本を登録しても、名前が重なることは事実上ない。重なるには 8 文字の符号も一致する必要があり、その確率は約 43 億分の 1 である。名前は自由に変えてよい。0.7.0 までに作った本 ID の名前のページや、「本の表記をそろえる」で書名を直したページは、「ファイル名を書名に合わせる」コマンドで、いまの書名から決まる名前に変えられる。コマンドは変える前と後の名前を一覧で示し、選んだページだけを変える。ほかのページからのリンクが書き換わるのは、Obsidian の「設定」→「ファイルとリンク」で「内部リンクを自動更新」が有効なときだけである。本ページへのリンクがあるなら、有効にしてからコマンドを使う。

「本の一覧を作る」コマンドは、Vault の直下に `本の一覧.base` を作って開く。Obsidian 標準の Bases で書籍フォルダの本を一覧するファイルで、表紙、すべての本、出版社別、著者別、欲しい本、読書状態別の表示がある。同じ名前のファイルがすでにあるときは、書き換えずに開く。書籍フォルダを変えた後などに作り直すときは、このファイルを削除してからコマンドを使う。複数の著者や出版社を持つ本は、そのままでは組み合わせごとに別の組になるため、著者別は筆頭著者で、出版社別は版の出版社を「・」でつないだ名前でまとめる。本ページに `![[本の一覧.base#同じ著者の本]]` と書くか、`本の一覧.base` を右サイドバーに移して表示を「同じ著者の本」にすると、開いている本と著者が重なる本が並ぶ。

## 通信、Vault 外のファイル、プライバシー

- **国立国会図書館サーチ**：ISBN か書名で書誌を探すと、入力した語を `https://ndlsearch.ndl.go.jp/api/opensearch` に送り、結果を読む。
- **国立国会図書館サーチ（拡張からの登録の後）**：拡張から ISBN のある本の購入・所持・欲しい本を登録すると、プラグインは先に本ページを保存し、その後で ISBN を同じアドレスに送って、書名・著者・出版社・シリーズを国立国会図書館の書誌にそろえる。問い合わせは一件ずつ間をあけて送る。混み合っていると断られたときは、待ってから三回まで問い直し、それでも答えが得られなければ後でやり直す。バッジの照合では問い合わせない。コマンド「本の表記をそろえる」は、国立国会図書館サーチで確かめる項目を選んだときだけ、登録済みの本の ISBN を送る。
- **書店の商品ページ**：商品 URL で書誌を探すと、対応サイトのそのページを、クエリ文字列を除いて取得する。
- **ブラウザ拡張との接続**：プラグインは `127.0.0.1` だけで待ち受け、同じ端末の拡張からの接続を受ける。書籍のデータは TLS 1.3 の中でやり取りする。Book Props 独自のサーバーはない。
- **Vault 外のファイル**：接続用フォルダ `~/Book Props/<Vault 名>/` には、端末内の接続先、書籍フォルダを示す不透明な識別子、起動中の TLS の信頼アンカー、一度だけ使うペアリングの検証値を置く。本の内容、鍵、セッショントークンは置かない。ペアリングを解除したときや書籍フォルダを変えたときに削除する。版を別の本へ移すと、移した版の控えを Windows では `%LOCALAPPDATA%\BookProps\edition-moves\`、Linux では `$XDG_DATA_HOME/BookProps/edition-moves/`（未設定時は `~/.local/share` の下）に残す。
- **外部プログラム**：Windows では、接続用フォルダに書き込めるのが自分のアカウントだけであることを、Windows 標準の PowerShell で確かめる。
- **ブラウザ拡張**：接続設定で同意した後、対応サイトの商品ページから、ページのアドレスと、書名、著者、ISBN、版の表記、出版社、発行日、表紙画像のアドレスを読み取る。ページのアドレスは拡張の中だけで使い、書誌は同じ端末の Obsidian にだけ送る。詳しくは[プライバシーポリシー](PRIVACY.md)を参照する。

利用状況の送信、広告、アカウント、課金はない。
