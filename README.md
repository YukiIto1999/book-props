# Book Props

Check which books you own or want on bookstore product pages, and keep your library and reading notes in Obsidian. Each book has one Markdown note. A revised edition is distinct from the original; print and digital copies count as the same edition when their content is the same.

## Installation

Download the installation ZIP from [GitHub Releases](https://github.com/YukiIto1999/book-props/releases). It contains both the Obsidian plugin and the Chrome extension. Follow the [Windows installation and maintenance guide (Japanese)](docs/installation.md) to install and pair them. Book Props is not distributed through the Chrome Web Store or Obsidian Community Plugins.

The Chrome integration runs alongside desktop Obsidian on the same computer. It does not require a separate server, database, or sync service. Windows and Linux are supported for local key storage. On mobile, you can read synced Markdown notes, but the plugin and extension do not run there.
